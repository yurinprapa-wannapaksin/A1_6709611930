Reflection

ปัญหาหรือความท้าทายที่พบคืออะไร และแก้หรือรับมืออย่างไร

  • ปัญหาหรือความท้าทาย: มีการสับสนและไม่เข้าใจใน Semantic Elements ในช่วงแรก และไม่รู้จะจัดระเบียบรูปหน้าอย่าไรให้ออกมาตรงกับที่จัดวางละออกแบบไว้
  • วิธีรับมือ: ศึกษาเพิ่มเติมจากใน W3Schools, Google และ Gemini ในการสอบถามเป็นแนวทาง

จากการทำ A1 นี้ เข้าใจอะไรกี่ยวกับการพัฒนาเว็บไซต์มากขึ้น

  • เข้าใจการนำบริบทของ Semantic Elements ในการออกแบบเว็บไซต์มากขึ้น
  • ได้เรียนรู้ว่า วิธีการออกแบบหน้า Website สำหรับ CSS ไม่ได้มีแค่ Grid

หากได้พัฒนางานนี้ต่อ อยากปรับปรุงหรือเพิ่มอะไร และเพราะอะไร

  • อยากเพิ่มเติมหน้า Website ให้มี function มากกว่านี้
  • อยากศึกษาการออกแบบ CSS เพิ่มเติม เพื่อมาพัฒนาให้ดีขึ้น
